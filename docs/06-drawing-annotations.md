# 大地图自由涂鸦与标注系统指南

为了满足战队作战规划、公会领地圈定、红石路线草图以及探险标记的需求，ChiyanMap 在全屏大地图中内置了专业级的 **矢量涂鸦标注系统（Drawing & Annotations）**。

涂鸦系统直接以 **Minecraft 世界物理坐标** 进行空间锚定，无论地图放大缩小还是平移漫游，笔迹与文字均能精准锁定在对应的地形方块上。

---

## 1. 开启涂鸦模式与界面工具栏

1. 按下 **`M`** 打开全屏大地图；
2. 点击大地图工具栏顶部的 **画笔图标 ✏️**，即可进入自由绘制标注模式；
3. 此时屏幕将展开涂鸦专属工具箱与浮动图层面板。

---

## 2. 绘制工具箱详解

| 工具类型 | 英文名称 | 交互方式与最佳应用场景 |
| :--- | :--- | :--- |
| **自由画笔** | `Pen` | 鼠标按住拖动即可勾勒连续平滑线条，适用于标记曲折的探险小径、河流流向或手写草图。 |
| **直线段** | `Line` | 点击起点并拖动至终点，自动拉直为笔直线段，适用于规划铁路轨道、地狱下界冰道走线。 |
| **战术箭头** | `Arrow` | 拖动生成带有标准箭头的导向线，非常适合多人生存战斗中的行军路线与撤退指引。 |
| **矩形选区** | `Rect` | 拖拉对角线生成矩形，支持实心填充或空心线框，常用于标示公会领地、建筑占地范围。 |
| **辐射圆圈** | `Circle` | 以鼠标落点为圆心拖出辐射圆圈，可用于标示村庄袭击范围、信标有效增益区或怪物生成警戒圈。 |
| **文字标签** | `Text` | 在地图目标位置单击，唤出中文输入框输入文本，支持自定义字号，生成常驻地图说明铭牌。 |
| **橡皮擦** | `Eraser` | 自带像素容差碰撞检测，点击已有图元即可瞬间抹除，支持撤销。 |

### 样式微调控制
在工具箱右侧，可实时调节当前绘制属性：
- **画笔颜色（Color）**：预设十六进制取色板与透明度滑块（RGBA）；
- **线条粗细（Thickness）**：从 `1px` 细线到 `16px` 加粗粗线条；
- **几何填充开关（Filled & Fill Color）**：开启后，矩形与圆形内部将以独立的半透明填充色渲染，打造专业地图蒙版效果。

---

## 3. 多图层管理系统（Layer System）

为了便于分类管理复杂的标注文档，ChiyanMap 引入了类似 Photoshop 的多图层架构：

```
[图层控制面板]
   ├── 📂 图层 1: [领地边界] ── 👁️ 显示 | 🔒 锁定 | 主题色: 蓝色
   ├── 📂 图层 2: [红石与铁轨] ── 👁️ 显示 | 🔓 可编辑 | 主题色: 橙色
   └── 📂 图层 3: [战术突袭路线] ── 🙈 隐藏 | 🔓 可编辑 | 主题色: 红色
```

- **新建与重命名**：可无限添加新图层并命名（如 `防空洞规划`、`矿道标记`）；
- **可见性开关（Eye Icon）**：点击眼睛图标可一键批量隐藏或显示该图层下的全部标注；
- **图层锁定（Lock Icon）**：重要工程规划完成后可锁定图层，防止在后续绘制或使用橡皮擦时不慎误触破坏；
- **不透明度（Opacity）**：每个图层均支持独立的 `0.05` 至 `1.0` 透明度滑块调节；
- **一键清空图层**：支持快速清空当前图层内所有元素，操作会自动推入撤销栈。

---

## 4. 完整的撤销（Undo）与重做（Redo）

绘制过程中难免有画错或误删的时刻，涂鸦系统提供了桌面绘图软件级别的撤销体验：

- **撤销（Undo）**：在涂鸦模式下随时按下 **`Ctrl + Z`**，立刻撤销上一次笔画、形状添加、橡皮擦擦除或图层清空操作（历史深度达 60 步）；
- **重做（Redo）**：按下 **`Ctrl + Y`**（或 **`Ctrl + Shift + Z`**），即可重新恢复刚才撤销的动作。

---

## 5. 数据持久化储存

所有的矢量标注均以轻量高效的 JSON 格式实时保存在本地，即使关闭游戏重新进入，笔迹位置分毫不差：

- **路径规则**：`mods/ChiyanMap/drawings/<World_ID>_<Map_ID>_dim<Dimension_ID>.json`
- **安全保障**：在模组退出、切换维度或更换地图实例时，系统自动执行原子写入与数据落盘，无惧突然断电或程序强退。
