# 快捷键、设置与性能调优指南

ChiyanMap 提供了极其丰富的可定制性。无论是按键习惯、界面视觉、多语言界面，还是底层磁盘 I/O 写入吞吐与显卡帧率，均可在设置系统中细致调节。

---

## 1. 快捷键重绑定系统（Hotkeys）

在全屏大地图点击齿轮图标，切换到 **快捷键设置（Hotkeys）** 面板：

### 1.1 极简按键监听
- 点击任意功能对应的按键按钮，按钮将变更为高亮等待状态（`[请按下任意按键...]`）；
- 直接在物理键盘上按下你想要绑定的按键即可完成修改，配置即刻存盘生效。
- 按下 **`Esc`** 可随时取消本次重绑。
- 若需清除该热键，可点击右侧的重置/禁用图标。

### 1.2 组合键支持（Modifiers）
系统不仅支持单键（如 `M`, `U`, `N`），更完整支持 Windows 复合修饰键：
- 例如可自由组合为：`Ctrl + M`、`Shift + Alt + W`、`Ctrl + Shift + F` 等。
- 系统在底层采用无冲突物理键位扫描技术（`ReadPhysicalKeyState`），在输入文字时智能避让，在游戏激烈对战中极速响应。

### 1.3 快捷键修改撤销（Ctrl+Z）
如果不小心把关键热键改乱，在快捷键设置面板中直接按下 **`Ctrl + Z`**，系统将自动撤销刚才的重绑操作，恢复上一次的有效键位。

## 2. 搜索栏与一键出厂复位

### 2.1 实时模糊搜索（Search Filter）
小地图与大地图设置面板中包含数十项细分参数。为了方便快速定位，面板顶部内置了 **实时搜索栏**：
- **多语言与拼音模糊搜索**：输入英文（如 `scale`, `radar`）、中文（如 `缩放`, `雷达`, `不透明度`）甚至拼音简写，均可瞬间过滤并展开匹配项；
- 统计栏实时显示匹配项总数（如 `匹配到 4 个配置项`），搜索框随时可一键清空。

### 2.2 双粒度出厂恢复（Factory Reset）
- **单项重置**：每一个滑动条或数值项右侧均配有小巧的撤回箭头（`↺`），点击即可将该参数单独复原至官方出厂标准；
- **面板/全局重置**：底部设有“恢复默认设置”按钮，点击后弹出防误触二次确认弹窗，确认后整页参数重置并即时刷新 GPU 渲染纹理。

## 3. 原生独立输入法支持（Native IME）

在以往的基岩版 ImGui 模组中，中文输入法往往无法唤出、或者打字会导致游戏画面强制暂停失焦。

ChiyanMap 研发了 **悬浮宿主式原生输入法桥接系统（NativeIME）**：
- 完美支持微软拼音、搜狗拼音、微信输入法等各大中文及多语言输入法；
- 在路径点命名、搜索栏过滤、坐标输入框以及大地图涂鸦文本框中，输入法候选框平滑浮动于光标旁边，打字行云流水；
- **防暂停拦截**：输入期间智能欺骗游戏底层窗口激活状态机，打字时游戏画面绝不锁帧暂停。

## 4. 存储架构与性能调优（Performance & Database）

对于长时间运行的大型多人服务器或已探索数十万方块的超大生存世界，系统提供了深度的底层性能调谐开关：

### 4.1 SQLite WAL 高速数据库 vs JSON 模式
- **`useSqliteDatabase` 开关**：
  - *开启后（推荐）*：模组将启用内置的 SQLite3 存储引擎，开启 `WAL (Write-Ahead Logging)` 日志模式、`NORMAL` 同步以及 `MEMORY` 临时缓存区；
  - 拥有极高的磁盘高并发读写吞吐，即便在极速鞘翅飞行或高速下界矿车中高频存盘，也能做到 **0 掉帧卡顿**。
  - *关闭后*：数据以标准人性化的 `.json` 格式保存，方便用户使用文本编辑器直接查阅与编辑。

### 4.2 快速批量写入（Fast Writes & Interval）
- **快速写入模式（`fastWritesEnabled`）**：将分散的区块高度与群系变更合并为内存批处理队列；
- **批处理间隔（`writeBatchIntervalMs`）**：可在 `100ms` 至 `2000ms` 之间按需调节，在机器性能较为紧张时增大批处理间隔，可大幅降低固态硬盘（SSD）的写入磨损与 CPU 占用。

### 4.3 小地图帧率限制（Minimap FPS Limit）
- 小地图默认随游戏渲染帧率（如 144Hz / 240Hz）高刷渲染；
- 如果在核显或轻薄本上运行游戏，可在设置中将小地图独立限制为 `30 FPS` 或 `60 FPS`，以极少平滑度代价降低整机功耗与发热。
