# 路径点与死亡记录系统指南

路径点（Waypoints）与死亡记录（Death Points）是生存与探险中不可或缺的导航支柱。ChiyanMap 拥有完备的路径点集合分类系统、原版 3D 信标光柱投射以及防误删撤销机制。

---

## 1. 路径点管理器（Waypoint Manager）

按下默认快捷键 **`U`** 即可呼出独立的路径点管理面板：

### 1.1 增删改查
- **新建路径点**：点击“新建路径点”按钮，系统会自动预填充当前玩家所在的三维坐标与当前维度，玩家只需输入名称（支持中英文）并挑选专属主题颜色。
- **色彩选择**：提供丰富的预设色彩板（红、橙、黄、绿、青、蓝、紫、粉、白等），支持十六进制与 RGB 微调。
- **独立显隐切换**：列表中每一个路径点前均配有独立开关眼睛按钮，点击即可单独隐藏或显示该点，操作 **即刻自动存盘**，无需手动保存。
- **误删撤销（Ctrl+Z 恢复）**：如果不慎删除了珍贵的基建或矿洞坐标，在路径点面板或大地图中直接按下 **`Ctrl + Z`**，系统将即刻从最近历史堆栈（最多支持 64 条记录）中完全复原被删路径点及其全部属性。

## 2. 路径点集合（Waypoint Sets）与分类文件夹

为了避免成百上千个路径点在同一张地图上造成视觉过载，ChiyanMap 设计了双层收纳体系：**集合（Sets）** 与 **文件夹（Folders）**。

### 2.1 路径点集合（Waypoint Sets）
集合是最高层级的隔离单位（类似分组工作区），例如可创建：`主城生活`、`地狱交通`、`矿脉勘探`、`跑图遗迹`：
- **热键切换**：默认可通过按下 **`[`** 与 **`]`** 键直接循环切换至上一个或下一个集合。
- **平滑通知（Toast）**：切换集合时，屏幕正中央会浮现出精美的高清 Toast 悬浮通知卡片，告知当前激活的集合名称并平滑淡出，游戏全程无需停步打开菜单。
- **独立过滤**：在小地图与 3D 渲染设置中可勾选“仅显示当前集合”，只保留当前专注任务的导航标记，彻底告别地图杂乱。

### 2.2 自定义分类文件夹（Folders）
在集合内部，还可为路径点分配所属文件夹（如 `刷铁机`、`史莱姆农场`、`掠夺者前哨站`）：
- 文件夹支持在管理抽屉中折叠或展开；
- 支持针对整个文件夹批量调整显隐状态或统一迁移。

## 3. 游戏内 3D 空间指示器与贯天信标光柱

ChiyanMap 不止于 2D 地图渲染，更将路径点无缝投射到真实的 3D 游戏世界中。

```
[远方天空]
   │
   │  ── 原版 3D 旋转能量信标光柱 (与路径点颜色同色)
   │
   ├── [主基地 (238m)] ── 3D 悬浮文字指示器 (随视线距离自适应缩放)
   │
[地表方块]
```

### 3.1 原版信标光柱管线（Native Beacon Beams）
不同于传统模组使用粗糙线条绘制假光柱，ChiyanMap 创新性地挂钩了 Minecraft 原版方块实体渲染管线（`LevelRendererCamera::$renderBlockEntities`）：
- **真实信标质感**：每一个启用的路径点都会从地底向上直冲云霄，投射出道地道地的原版信标光柱；
- **自转与色彩联动**：光柱自带原版能量流动纹理与周期自转动态，颜色与路径点设定的色彩完全一致；
- **极限能效**：由显卡顶点管线以原生着色器高帧率渲染，绝不消耗 CPU 资源。

### 3.2 3D 空间距离指示悬浮牌
- 在视野正前方，路径点会悬浮标明名称与物理直线距离（如 `末地要塞 [1450m]`）；
- 距离过远时文字自动半透明缩小，接近时平滑放大，并提供视线遮挡测试。
- 可在设置中自由调节 **3D 标记最大渲染距离**（从 64 格到数千格）。

## 4. 死亡记录系统（Death Points）

在危险的探索与战斗中，意外牺牲往往带来掉落物遗失的焦虑。

### 4.1 自动捕捉与精准记录
- 玩家生命值归零瞬间，系统底层即刻安全拦截并记录当前物理坐标（精确到小数点后一位）、发生时间戳（精确到秒）以及所属维度。
- 自动生成死亡记录卡片，格式为：`死亡点 YYYY-MM-DD HH:MM:SS`，并在小地图及大地图上标注醒目的鲜红骷髅徽标。

### 4.2 一键转为永久路径点（Convert to Waypoint）
在死亡点管理面板中，每一个死亡点均配有 **转为路径点** 按钮：
- 点击后自动将此死亡坐标固化为一条永久常规路径点，光柱直插死亡现场上空；
- **跨会话持久联动**：系统会在底层 JSON 中记录 `convertedWaypointId`。即使重启游戏，若该路径点被用户在路径点管理器中删除，死亡点列表中的“转为路径点”按钮将自动重新激活；若撤销删除恢复路径点，按钮又会智能保持锁定状态，逻辑天衣无缝。

### 4.3 智能自动清除安全期（Auto Removal）
- **自动清理机制**：开启“到达死亡点后自动清除”选项后，当玩家重新跑图靠近至遗址周围 6 格以内时，系统判定已成功捡包，自动销毁该死亡记录。
- **5 秒免删安全期**：内置 5 秒重生缓冲守卫，防止因床位/重生锚紧邻死亡点导致刚复活就误删死亡点记录的情况。
