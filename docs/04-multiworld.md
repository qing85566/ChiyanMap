# 多世界与地图实例管理指南

在大型多人服务器、群组服（BungeeCord / Velocity）、小游戏大厅或经常跨服联机的场景中，玩家常遇到**地图数据串线混淆**的困扰——例如从小游戏大厅切换至空岛生存服时，两个完全不同世界的地形被错误拼接在同一张地图上，导致缓存被覆盖损坏。

**ChiyanMap 的多世界管理引擎（Multiworld Manager）** 从底层彻底解决了该问题，为每个世界和子服赋予了完全独立的地图实例（Map Instance）体系。

---

## 1. 为什么需要多世界管理？

- **物理隔离**：每一个地图实例拥有独立的缓存文件夹、独立的路径点数据库、独立的图层标注以及维度高度图。
- **自动适配**：换服时无需手动清理本地缓存文件，系统按需隔离，互不干扰。
- **漫游互联**：允许用户自定义世界之间的“互联（Connected）”关系，让生存服子服之间能够共享航点，同时阻止误传送到未连接的独立游戏区。

---

## 2. 地图选择模式（Selection Modes）

在设置面板或地图管理界面中，可自由选择以下三种匹配模式：

### 2.1 出生点自动识别模式（WorldSpawn - 推荐）
- 系统每帧自动监听底层世界的物理出生点坐标（`spawnX`, `spawnZ`）。
- 一旦玩家跨服或进入新小游戏，出生点坐标发生变化，系统将在毫秒级内自动检索是否存在关联该出生点的地图实例：
  - 若已存在匹配实例：**静默无缝切换**至目标地图；
  - 若为首次访问的新世界：**自动创建新地图实例**，命如 `Spawn (100, 200)`，杜绝地形串线。

### 2.2 手动管理模式（Manual）
- 地图切换完全由玩家自主控制，在管理窗口中自由点击指定的地图实例进行激活。
- 适用于出生点相同但需要建立“平行开荒档”或“特殊建筑规划图”的进阶玩家。

### 2.3 单地图模式（Single）
- 经典极简模式，所有探索的区域均合并写入该世界的 `default` 默认地图实例中。

---

## 3. 地图实例生命周期管理

在大地图点击顶部多世界管理按钮，可呼出完整的实例控制面板：

### 3.1 创建与重命名
- 点击 **新建地图（New Map）**，输入自定义名称（如 `纯净生存服`、`红石测试世界`），系统将即刻分配独立的 UUID 与储存目录。
- 支持随时随地对已有地图进行重命名，名称即时刷新，配置自动持久化。

### 3.2 级联清理与安全删除（Delete Map）
为了保护玩家资产，ChiyanMap 设计了严格的防误删机制：
- **核心防护**：禁止删除当前正在激活运行的地图或系统的 `default` 基础地图。
- **自动热备份**：点击删除某张地图时，系统会自动将其原始数据压缩归档至 `cache/<worldId>/maps_backup/` 目录中，即使误操作也能从备份文件夹挽回。
- **级联深度清理**：彻底消除磁盘垃圾文件，自动同时清理该地图附属的各维度二进制区块（`region_*.bin`）、洞穴数据（`cave/`）、独立路径点、集合分类及涂鸦标记。

---

## 4. 地图互联与跨图传送预警（Map Connection）

### 4.1 互联漫游设置（Connected Maps）
在多世界面板中，可将两张或多张地图建立双向勾连：
- 例如：`生存服主世界` 与 `资源采集服` 勾选互联后，两者的路径点可在同一张导航列表中相互索引查看。
- 自身与自身默认永久互联。

### 4.2 传送防跳崖安全拦截
当玩家在全屏大地图中点击某路径点尝试使用 `/tp` 指令传送时：
- 系统首先核验当前所在地图与目标路径点所属地图是否具有互联关系；
- **非互联阻断预警**：若玩家试图传送到一个未互联的异构地图，系统会弹出黄色警告确认弹窗（“检测到该航点属于未互联的地图实例，盲目传送极可能掉入虚空或窒息在方块中”），必须二次确认方可执行，极大提升硬核生存安全性。

## 5. 存储架构对照

数据按以下标准层次严谨保存在客户端根目录下：

```
mods/ChiyanMap/
├── cache/
│   └── <World_UUID>/
│       ├── multiworld.json          # 多世界配置清单与互联关系表
│       ├── dim_0/                   # 默认地图主世界区块二进制数据
│       ├── dim_1/                   # 默认地图下界区块
│       ├── dim_2/                   # 默认地图末地区块
│       └── maps/
│           └── <Map_Instance_ID>/   # 自定义地图实例独立目录
│               ├── dim_0/           # 独立主世界区域
│               └── dim_0/cave/      # 独立洞穴层数据
└── waypoints/
    ├── <World_UUID>_dim0.json       # 默认地图路径点
    └── <World_UUID>_<Map_ID>_*.json # 自定义实例的独立路径点与集合
```
