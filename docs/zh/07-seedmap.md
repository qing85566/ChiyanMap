# 种子地图与结构预测指南

[English](../en/07-seedmap.md) | **简体中文** | [返回文档首页](../README_zh.md)

以往玩家寻找要塞、远古城市或史莱姆区块时，往往需要切出游戏打开网页版工具（如 Chunkbase），繁琐且无法实时定位。

ChiyanMap 创新性地在客户端内直接嵌入了基岩版世界生成算法库（基于深度优化的 `cubiomes-bedrock` 引擎），打造出 **原生内置种子地图（Seed Map）**。

---

## 1. 种子获取与状态指示

在大地图工具栏中点击 **种子地图（Seed Map）** 图标，即可呼出预测面板：

- **自动捕获（Auto Capture）**：在本地单人存档、局域网联机或开放了种子广播的服务器中，模组会在玩家加载世界的瞬间自动从游戏内存底层捕获世界的 64 位种子（Level Seed），无需玩家手动敲命令查询。
- **手动输入（Manual Input）**：若身处隐藏种子的服务器中，且玩家已通过服主获知种子，可在种子面板中手动输入正负数字种子或文字种子，点击确认后即刻开启全图演算。
- **种子状态卡片**：顶部明确标示当前世界使用的种子数值、种子有效状态以及生成版本基准（对齐 Minecraft 1.26+ 最新基岩版地形特性）。

---

## 2. 全结构生成预测（Structures）

系统能够在完全未探索的战争迷雾区域，以极高精度推演出各大自然遗迹的生成坐标与外接盒边界：

| 维度分类 | 支持预测的结构类型 | 图标与标注特征 |
| :--- | :--- | :--- |
| **主世界文明** | 平原/沙漠/热带草原/针叶林/雪原村庄、掠夺者前哨站、雪屋 | 房屋图标，标明村庄类型 |
| **地底探险** | **末地要塞 (Stronghold)**、**远古城市 (Ancient City)**、废弃矿井 | 传送门图标 / 幽匿图标 |
| **大型建筑** | **林地府邸 (Woodland Mansion)**、**海底神殿 (Ocean Monument)**、试炼密室 (Trial Chamber) | 宏伟建筑剪影图标 |
| **野外遗迹** | 沙漠神殿、丛林神殿、女巫小屋、埋藏的宝藏、古迹废墟 (Trail Ruins) | 金字塔/宝箱图标 |
| **下界地狱** | **下界要塞 (Nether Fortress)**、**堡垒残骸 (Bastion Remnant)** | 烈焰人/猪灵猪鼻图标 |
| **末地深空** | **末地城 (End City)**、末地折跃门 (End Gateway) | 潜影贝/紫颂塔图标 |

### 交互与导航
- **分类过滤**：面板中配有多选过滤器，可勾选只显示特定结构（如仅查找“远古城市”与“末地要塞”），避免密集的图标遮挡视野；
- **悬停与坐标定位**：鼠标指针悬停于任意遗迹图标上，将即时浮现该结构的准确三维坐标、所属生物群系以及距玩家当前的直线距离。

---

## 3. 史莱姆区块计算（Slime Chunks）

建造高效大型史莱姆农场必备利器：
- 基岩版拥有专属的史莱姆区块伪随机判定公式；
- 在种子地图面板中开启 **史莱姆区块（Slime Chunks）** 开关；
- 大地图与小地图上所有符合条件的区块（16x16 方块网格）均会被覆盖上一层 **半透明翠绿色高亮网格**；
- 协助玩家精准规划垂直挖掘坑道，绝不挖错一格。

---

## 4. 未探索地貌全景预演（Biomes Preview）

- 种子地图能够在玩家尚未涉足的数万格远方，根据生物群系噪声采样算法，实时计算出陆地与海洋的轮廓、群系分布与山川起伏。
- 无论是寻找罕见的蘑菇岛（Mushroom Fields）、深暗之域（Deep Dark）还是苍白之园（Pale Garden），只需在大地图中拖拽缩放即可一目了然，彻底免除盲目跑图的困扰。
