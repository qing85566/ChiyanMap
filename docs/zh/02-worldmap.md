# 全屏大地图与图像导出指南

[English](../en/02-worldmap.md) | **简体中文** | [返回文档首页](../README_zh.md)

按下默认快捷键 **`M`** 可呼出全屏大地图（World Map）。大地图为玩家提供宏观的探索全貌、跨维度浏览、精准坐标跳转以及高清地图图片导出能力。

---

## 1. 基础漫游与视角操控

### 1.1 鼠标操控手感
- **平移漫游**：在地图任意区域按住 **鼠标左键** 拖拽，即可随心平移视野。平移算法内置惯性阻尼平滑滤镜，镜头移动柔和顺畅。
- **自由缩放**：滚动 **鼠标滚轮** 进行缩放。缩放范围广阔（从局部方块特写到数千格超大视野宏观预览），缩放中心始终紧随当前鼠标指针所在的世界坐标点。
- **一键居中（Center on Player）**：点击底部工具栏的“定位玩家”按钮（或按下空格键），视野将平滑居中锁定至玩家当前物理站位。
- **光标静止记忆**：模组记录用户在大地图内点击或移动光标的精确位置，关闭并重新打开大地图时，光标精准停留在上次浏览的区域，避免视角错位。

### 1.2 坐标精准跳转（Goto Coordinates）
在全屏大地图顶部栏设有坐标输入框：
- 输入目标 **X** 与 **Z** 坐标，点击 **前往（Go）** 按钮或按下回车。
- 视野将自动以高帧率平滑滑行到目标区域上空，并在目标坐标处高亮指示光圈，是远距离探险与跑图规划的绝佳工具。

---

## 2. 跨维度浏览与换算

在大地图顶部维度切换栏中，玩家可自由在 **主世界 (Overworld)**、**下界 (Nether)** 与 **末地 (The End)** 之间切换视角：

```
[当前玩家所处维度: 主世界]
   └── 点击切换至 [下界]
         ├── 自动载入下界已缓存的地貌与熔岩海
         ├── 光标悬停处同步计算对应的主世界地表门坐标 (X*8, Z*8)
         └── 关闭大地图瞬间：自动重置回主世界物理维度，不干扰游戏逻辑
```

- **坐标联动折算**：在下界浏览时，界面右下方会实时显示该指针位置折算到主世界的门对接坐标；反之在主世界浏览时，也会同步提示下界交通穿梭门所需的对应坐标，极大方便下界冰道与地狱交通网的铺设规划。
- **独立维度记忆**：可在设置中开启“保持最后浏览维度”，方便长期沉浸式观察特定维度的地形。

## 3. 实体头像雷达与内嵌路径点抽屉

### 3.1 实体头像热键切换（Tab Hold）
在大地图模式下，周围所有玩家、动物与怪物均会以彩色微缩圆形头像或微缩皮肤展示：
- **临时显隐快捷键**：长按 **`Tab`** 键可一键临时切换所有生物头像的显示状态。
- **输入状态智能避让**：即便此前曾点击过坐标跳转输入框，当用户按下实体头像热键时，系统会自动解焦输入控件，确保快捷键不会变成文字输入而影响操作。

### 3.2 大地图内嵌折叠路径点抽屉（Waypoint Drawer）
无需单独开启管理器弹窗，在大地图左侧边缘设有折叠式路径点抽屉：
- 点击展开抽屉，即可浏览当前维度与集合下的所有路径点列表。
- **点击对齐镜头**：点击列表中任意路径点，大地图镜头将即时平滑跳转并聚焦至该路径点坐标，抽屉可配置为点击后自动折叠，保持地图开阔清爽。

## 4. 框选高清导出 PNG（Map Export）

想要将自己探索的壮丽世界制作成高清全景壁纸或战队分享图？ChiyanMap 提供了专业级的图片导出工具。

### 4.1 快捷键框选模式
1. 打开全屏大地图（**`M`**）；
2. 按住 **`Shift`** 键（快捷键可自定义绑定），在地图上按住 **鼠标左键并拖拽**；
3. 画面上将出现半透明高亮矩形选区，右上角实时显示选区尺寸（例如：`选区宽度: 2048 格, 长度: 2048 格`）；
4. 松开鼠标左键，即刻弹出 **PNG Export 确认面板**。

### 4.2 导出配置与参数
- **全景拼接引擎**：内置分块瓦片烘焙算法，即使框选跨越数十个已探索 Region（区域），系统也会在后台以最高精度拼合各像素块的地形、群系染色、高度光影与水体透明度。
- **输出路径**：点击 **开始导出（Export）**，图片将生成为无损 PNG 格式并保存至游戏客户端根目录下的 `mods/ChiyanMap/exports/` 目录中。
- **完成提示**：导出完成后屏幕将弹出绿色 Toast 提示，并附带可一键复制的本地图片绝对路径。
