# 小地图与高级雷达系统指南

[English](../en/01-minimap.md) | **简体中文** | [返回文档首页](../README_zh.md)

小地图（MiniMap）是 ChiyanMap 呈现给玩家的核心常驻 HUD 界面，具有高帧率呈现、丰富的图元信息与强大的实体雷达探测能力。

---

## 1. 基础外观与交互控制

### 1.1 形状与朝向模式
- **形状切换**：默认可通过按下快捷键 **`Y`** 在 **圆形（Circular）** 与 **方形（Square）** 之间即时切换。
  - *圆形模式*：视野柔和对称，边框罗盘刻度自然环绕。
  - *方形模式*：四角可视面积增加约 27%，利于观察斜向远距离地标。
- **旋转模式**：默认可通过按下快捷键 **`J`** 切换朝向驱动方式：
  - *随玩家旋转*：小地图始终以玩家当前视线朝向为“上方”，地图纹理随身体转动平滑旋转。
  - *固定正北*：地图上方始终锚定游戏世界的绝对正北（Z 轴负方向），玩家箭头在小地图内自主旋转。

### 1.2 自由拖拽与尺寸微调
按下 **`M`** 打开全屏大地图，点击齿轮图标进入 **小地图设置**：
- **位置拖拽**：直接在界面中用鼠标按住小地图窗口拖动至屏幕任意位置（左上、右上、屏幕底部等）。
- **界面缩放（Scale）**：支持从 `0.5x` 至 `2.5x` 无级滑块缩放，适应 1080P、2K 及 4K 高分辨率显示器。
- **视野半径（View Radius）**：可设定探测方块范围（16 到 128 格），随性能与偏好自由调整。
- **显隐开关**：快捷键 **`N`** 可一键完全隐藏或呼出小地图，不影响游戏正常渲染。

### 1.3 放大模式（Enlarge Minimap）
按下默认快捷键 **`Z`** 可激活临时放大模式：
- 小地图将即时放大并居中显示于屏幕中央，视野范围扩大 2 倍以上。
- 松开按键（或再次按下切换键）后立即恢复默认角隅显示，极其适合在复杂战斗或洞穴中快速确认战术方位。

## 2. 智能避让与信息 HUD

### 2.1 原生药水状态效果推挤避让（Pushbox）
当玩家处于右上角布局且拥有药水增益/减益效果时，游戏原生药水图标往往会与小地图发生遮挡冲突：
- ChiyanMap 内置 **HUD 避让系统**，实时感知活跃状态效果数量。
- 当检测到药水图标激活时，小地图将智能平滑向下偏移，始终与原生药水栏保持安全距离；效果消失后自动回弹。

### 2.2 仪表盘信息项配置
小地图四周可自定义开启以下高价值生存指标：
- **三维坐标与维度换算**：显示当前物理 X, Y, Z 坐标；位于主世界时同步提示下界等效坐标（1:8 折算），位于下界时同步提示主世界门对应坐标。
- **生物群系识别**：实时读取脚下群系，剥离命名空间并映射为精准本地化中文（如 `樱花树林`、`苍白之园`、`繁茂洞穴`）。
- **环境光照检测**：以 `天顶光 (Sky) / 方块光 (Block)` 分离显示，便于判断夜晚怪物生成条件与插亮安全区。
- **动态时钟与天数**：读取世界游戏刻，精准换算为游戏内 24 小时制时间（如 `12:30`）及累计生存天数。
- **气象预警**：实时判定当前群系温度与降水条件，直观呈现晴朗、降雨或暴风雪图标。

## 3. 高级实体雷达系统

小地图不仅绘制地形地貌，更能通过原生接口获取周围实体，构建多层立体雷达。

```
[玩家中心]
   ├── 被动型生物 (牛/羊/猪等) ── 绿色点位 / 头像
   ├── 敌对型怪物 (僵尸/骷髅/苦力怕等) ── 鲜红色点位 / 头像
   ├── 中立型生物 (末影人/铁傀儡等) ── 黄色点位
   ├── 其他玩家 ── 专用高亮圆环与玩家皮肤微缩头像
   └── 已驯服宠物 ── 双层荧光绿光环 + 爱心标记
```

### 3.1 景深淡出高度差（Depth / Height Fade）
实体雷达拒绝扁平化，引入 Y 轴垂直距离感知：
- 在设置面板中可调节 **高度差感知阈值**（1.0 ~ 30.0 格）。
- 位于玩家同层或接近层高时，实体以 100% 不透明度呈现；
- 当实体处于上方高山或地下深洞时，图标随高度差线性渐隐变暗，并显示微小向上或向下指示三角，快速分辨高低差。

### 3.2 越界吸附边框滑行（Border Clamping）
当周围实体离开小地图可视范围但仍处于雷达最大探测半径内时：
- 提供 **5 种吸附边缘模式**；
- 实体圆点会自动吸附并平滑滑行在小地图的内侧边缘上，伴随微型外指箭头；
- 使得潜行逼近的敌对玩家或远处的同伴即使超出视野也绝不会从雷达上遗漏。

### 3.3 通配符高级过滤（Wildcard Filtering）
通过设置面板中的雷达过滤栏，可自由配置实体黑白名单：
- **包含规则与排除规则**：支持输入实体标识符（如 `zombie`, `skeleton`, `creeper`）。
- **通配符支持**：支持 `*`（匹配任意字符）与 `?`（匹配单个字符）。例如 `*skeleton*` 可同时匹配普通骷髅、流浪者与凋灵骷髅。
- **逗号复合列表**：支持一行填入多个规则（如 `cow, pig, sheep, chicken`）。

### 3.4 已驯服生物专属光环
通过底层接口调用 `isTame` 原生检测：
- 已被玩家驯服的狼、猫、马匹等生物，在雷达上会额外附加一层 **专属双层荧光绿光环**；
- 悬浮命名牌顶端显示粉色爱心小图标，防止在激烈混战中误伤自家宠物。
