# 洞穴地图与无规则探测指南

[English](../en/05-cave-and-anarchy.md) | **简体中文** | [返回文档首页](../README_zh.md)

地底探险与无规则（Anarchy）服的遗迹搜寻是 Minecraft 探险中最硬核的环节。ChiyanMap 内置了专业的 **洞穴层切片透视算法** 以及 **无规则历史修改痕迹探测引擎**。

---

## 1. 洞穴地图模式（Cave Mode）

地表地图通常只记录光照照射到的最顶层实体方块。而在地下矿洞、远古城市（Ancient City）或下界要塞中，顶层方块往往是一整片厚重的岩石层，导致普通地图呈现为毫无信息的灰色平原。

**洞穴地图模式** 为此而生，它以玩家当前的垂直高度（Y 轴）为基准，对垂直切片进行动态空气与地板重构。

```
[地表岩石天花板] (被智能剔除忽略)
   │
   ▼
[空气通道层 (Air Corridor)] ── 洞顶搜索
   │
   ├── 玩家所在高度 Y
   │
   ▼
[坚实地板层 (Solid Floor)] ── 地板高亮 (渲染为可落足的洞穴走道)
   │
[底部熔岩海/深层岩石] ── 渲染为暗色阴影与断崖警示
```

### 1.1 核心工作机制
- **动态切片扫描**：以玩家站立点为轴心，向上搜索指定方块数的空气天花板，向下搜索坚实体方块地板。
- **立体层次渐变**：探测出的地底走廊走道根据高度差附加立体浮雕阴影，哪条隧道向上倾斜、哪条深渊向下贯通一目了然。
- **独立洞穴缓存**：已探索的洞穴数据单独存储于对应维度的 `cave/` 目录中，在全屏大地图上打开“洞穴模式”即可像查看地下建筑设计图一样复盘整座矿脉或要塞。

### 1.2 自动与手动切换
- **自动触发**：当玩家身处主世界且深入地下（Y < 55）或者上方完全被实体岩层遮蔽时，小地图可自动无缝过渡为洞穴渲染风格；
- **手动热键**：支持在大地图顶部或设置中强制开关洞穴模式，方便在地表提前查阅脚下深处是否有天然空腔或繁茂洞穴。

## 2. 无规则探测器（Anarchy History Analyzer）

在无规则（Anarchy / 2b2t）服务器或大型多人生存服中，**追踪旧日玩家足迹、搜寻废弃基地、排查藏匿箱与辨识陷阱** 是至关重要的生存技巧。

ChiyanMap 独创的 **无规则探测器** 能够穿透表象，敏锐捕获区块内任何非自然生成的人为修改痕迹。

### 2.1 痕迹捕捉维度
探测器通过对当前加载区块进行特征模式分析，识别以下关键指标：
1. **非自然人造方块**：黑曜石、哭泣黑曜石、末影箱、箱子、潜影盒、熔炉、工作台、书架、告示牌等人类文明产物；
2. **人工改造地形**：平整的黑曜石高速公路（Highway）、直线挖掘通道（Tunnel）、规则矩形人工基岩破洞；
3. **爆炸与凋灵破坏**：床炸/水晶炸遗留的放射状坑洞与不规则碎块；
4. **火把与光源分布**：洞穴内非自然分布的火把、荧石、红石火把及海晶灯。

### 2.2 视觉高亮渲染
- **区块热度网格**：在大地图或小地图上，将检测到有人类活动痕迹的区块以半透明橙色/红色网格高亮包裹；
- **高亮标记持久化**：发现的痕迹点位会自动持久化存盘（`AnarchyManager::SaveHighlights()`），即便离开该区域，此前勘测到的人类活动足迹在世界大地图上依然清晰可见，助你轻松绘制对手的基地网络路线图。

### 2.3 探测灵敏度配置
在设置面板进入 **无规则探测设置（Anarchy Settings）**：
- **触发阈值（Sensitivity Threshold）**：可调节触发高亮的最小人造方块数量，过滤掉零星随机刷新的自然方块；
- **扫描半径调节**：依据当前机器性能设定每秒分析的周边区块密度；
- **高亮图元清理**：提供一键清空历史痕迹标记，便于开始新一轮的隐秘巡查。
